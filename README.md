🎁 Surprise Anniversaire

Une petite surprise interactive créée en HTML, CSS et JavaScript pour souhaiter un joyeux anniversaire à un ami de manière amusante ! 🎂🎉

✨ Fonctionnalités

- 🎁 Une page d'accueil avec un message surprise.
- 📸 Accès à la caméra avant, uniquement après autorisation.
- ⏱️ Un compte à rebours de 3 secondes.
- 🤳 Une photo surprise avec aperçu.
- 🎊 Une animation de confettis.
- 📤 Le partage volontaire de la photo via les applications compatibles.
- 📥 Le téléchargement de la photo.
- 🌙 Une interface qui prend en charge les thèmes clair et sombre.
- 📱 Un design adapté aux téléphones et aux ordinateurs.

🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- API Web MediaDevices pour la caméra
- API Web Share pour le partage des photos

🚀 Démonstration

Site en ligne : À ajouter après la publication sur GitHub Pages.

📲 Installation et utilisation

1. Ouvrez le site depuis un navigateur compatible.
2. Appuyez sur « Clique ici 👀 ».
3. Autorisez l'accès à la caméra si vous souhaitez continuer.
4. Attendez la fin du compte à rebours.
5. Découvrez la photo surprise.
6. Choisissez de la partager ou de la télécharger.

🌐 Hébergement

Ce projet peut être hébergé gratuitement avec "GitHub Pages" (https://pages.github.com/).

Pour activer l'hébergement :

1. Ouvrez les paramètres du dépôt GitHub.
2. Accédez à Settings → Pages.
3. Choisissez Deploy from a branch.
4. Sélectionnez la branche "main" et le dossier "/ (root)".
5. Enregistrez les paramètres.

🔒 Confidentialité

- La caméra est sollicitée uniquement après une action de l'utilisateur.
- L'accès à la caméra nécessite son autorisation.
- La photo est créée localement dans le navigateur.
- Aucune transmission automatique de la photo vers le propriétaire du site n'est implémentée.
- Le partage ou le téléchargement dépend du choix de l'utilisateur.
